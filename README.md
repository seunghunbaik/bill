# 🧾 점심 영수증 정산

회사 점심 영수증을 이미지로 올리면 금액·날짜를 자동 인식하여 월별로 정산하는 웹 앱입니다.

## 주요 기능

- **OCR 자동 인식** — 영수증 이미지 업로드 시 Tesseract.js로 금액·날짜 추출
- **월 260,000원 한도** 관리 — 잔여 예산, 진행률 실시간 표시
- **평일 기준 일일 한도 계산** — 공휴일 제외 근무일 수로 하루 예산 자동 계산
- **오늘부터 하루 한도** — 남은 예산 ÷ 남은 평일 = 오늘부터 쓸 수 있는 금액
- **월별 목록** — 영수증 썸네일, 수정·삭제

## 시작하기

```bash
npm install
npm run dev   # http://localhost:5173
```
